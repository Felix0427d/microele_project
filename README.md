## 📄 Rapport écrit – Contenu attendu (18–30 pages)

Le rapport doit être rédigé en **anglais** et structuré de manière scientifique.

### 1. Context
- Présentation du projet  
- Objectifs  
- Description du design choisi  

### 2. State of the Art
- Revue de littérature scientifique  
- Analyse de solutions existantes  
- Positionnement du projet  

### 3. Design Description
- Description du design initial  
- Modifications apportées  
- Ajout de la testabilité  

### 4. OpenLane Hardening Workflow
- Description du flow OpenLane  
- Étapes suivies  
- Configuration utilisée  
- Résultats du flow  

### 5. Simulation
- Simulation avec NGSpice  
- Méthodologie  
- Résultats obtenus  

### 6. Verification
- Vérification avec Yosys  
- Analyse avec OpenLane GUI  
- Validation logique  

### 7. Testing
- Test sur FPGA (si réalisé)  
- Méthodologie  
- Résultats  

### 8. Validation
- Validation avec GTKWave ou oscilloscope  
- Comparaison avec comportement attendu  

### 9. Analysis and Discussion
- Interprétation des résultats  
- Limites du design  
- Problèmes rencontrés  

### 10. Conclusion
- Résumé des résultats  
- Améliorations possibles  
- Perspectives  

### 11. Appendix
